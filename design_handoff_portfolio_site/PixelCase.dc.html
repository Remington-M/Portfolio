04 · SQUARE ×2 · GOOGLE LOGO ANIMATION, PIXEL 2 WELCOME
Branded Moments
It was always fun to break out of the complicated System UI world and create some fun branded moments for Google on the Pixel phones. These animations were used to help welcome users to their Pixel phones and was one of the first things they would see when activating a new phone.
We wanted to update Android’s boot animation to something more branded with the launch of the Pixel phone. We decided to animate from the Google logo to the G letter mark.
05 · LANDSCAPE, CENTERED · BOOT ANIMATION
We needed to update Android’s boot animation to something more branded with the launch of the Pixel phone. We decided to animate from the Google logo to the G letter mark. There was already some great Google logo animations but none existed for this specific transition. With the Google logo being so iconic I sweated the details of every frame of this transition. This animation has since been used across many Google products beyond the Pixel phone. 
06 · PORTRAIT · APP OPENING
App Opening
I designed a new transition for opening apps on Android P. The previous design utilized a simple mask reveal that wasn’t very polished. The new transition was designed to grow and transition the app window directly from the app icon. This required a multi year collaboration with engineering on an animation synchronization API to be able to perfectly align the icon motion with the app window.
07 · DESKTOP · FOLDER ANIMATION
Folder Animation
One of the first projects that I worked on was improving the folder opening and closing transition. The prior transition utilized a mask reveal and a redesign of the visuals gave opportunity for a more direct and connected experience. While a fairly simple animation from first glance; great care went into considering icon positioning for large folders, multi page folders, rearranging icons within the folder, and more.
08 · PORTRAIT · TASK SWITCHING
Task Switching
Task switching is an animation that takes you from one application to another. This was a global system wide transition that was heavily utilized in Android. The transition was designed with a horizontal motion to help reinforce the new spatial model for Android O and help users understand where to find their previous task if they were looking for it.
