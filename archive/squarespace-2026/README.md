# The Squarespace site, as it stood before deletion

Captured 9 October 2026 from `remington-mcelhaney.squarespace.com`, the
built-in URL the site fell back to once `remingtonm.com` was pointed at
GitHub Pages. Kept because the account was about to be deleted and
Squarespace does not return anything afterwards.

Nothing here is wired into the site. It is not in `public/`, so the build
never sees it, and deleting this folder changes nothing.

## What is here

| file | what it is |
|---|---|
| `swipe-to-go-home.txt` | The Android 10 gesture navigation case study. The only substantial writing on the old site — about 5,000 characters on springs, velocity mapping, and tuning motion with engineering. |
| `meet-me.txt` | The old About page. Lead experience designer, 13 years, Google before Airbnb. |
| `home.txt` | The old home page. Three projects listed: Google Pixel, Gesture Navigation, The New Google Assistant. |
| `reel.txt` | A page holding one video: "Motion Reel - 2015". |
| `images/` | Every image the site served from Squarespace's CDN, requested at 2500w. These were the only assets that would have died with the account. |
| `raw/` | The HTML as served, in case something was missed in the extraction. |
| `media-manifest.json` | Per page: headings, image URLs, and embed URLs. |

## The videos were never Squarespace's

Every clip was a Wistia embed, so none of them were at risk from deleting
the Squarespace account — and none of them are in this folder, because
Squarespace never held them.

| page | Wistia id |
|---|---|
| `reel` | `mnmidplafb` |
| `swipe-to-go-home` | `0m1hxj1x97`, `c98gjljo1v`, `rc5vcgi6jx`, `ub92d5p9zj` |

They are only safe while that Wistia account exists. If it is ever closed,
these five need downloading first — this folder does not cover them.

## Worth knowing

The gesture navigation case study is the one thing here with a future. The
current site shows that work but says far less about it; the writing below
is the process account, and it is the kind of thing that is much easier to
keep than to write again.
